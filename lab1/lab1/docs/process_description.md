Название процесса: Оформление страхового полиса ОСАГО

Участники (роли): Клиент, Страховой агент, Андеррайтер, Служба верификации данных, Бухгалтерия.

Описание:
Клиент обращается в страховую компанию для оформления полиса и предоставляет агенту документы (паспорт, права, документы на автомобиль). Агент вносит данные в систему и параллельно запускает проверку клиента в базе данных ГИБДД и оценку истории страховых случаев. Если данные клиента корректны и история без нарушений, заявка передаётся андеррайтеру для расчёта тарифа; если обнаружены расхождения в документах, заявка возвращается клиенту на исправление. Андеррайтер рассчитывает стоимость полиса с учётом коэффициентов риска. Если стоимость превышает установленный лимит для стандартного оформления, заявка направляется на дополнительное согласование с руководителем отдела; в противном случае процесс идёт по обычному пути. После утверждения тарифа агент формирует проект договора и направляет его клиенту на подпись. Клиент подписывает договор и производит оплату через кассу или онлайн. Бухгалтерия фиксирует поступление платежа. После подтверждения оплаты система автоматически генерирует полис в электронном виде. Агент выдаёт клиенту готовый полис (в бумажном или электронном виде) и вносит запись о завершении сделки в CRM-систему.
